# Titanic Dataset Analysis – Data Science Internship Task 2

## 📌 Overview

This project presents an exploratory data analysis of the Titanic
passenger dataset using Python.

The main purpose of the project is to understand passenger survival
patterns and identify relationships between survival and factors
such as gender, passenger class, and age.

## 🎯 Objectives

- Load the Titanic dataset from Kaggle
- Understand the structure of the dataset
- Identify and handle missing values
- Perform exploratory data analysis
- Analyze survival by gender
- Analyze survival by passenger class
- Analyze survival by age group
- Create meaningful data visualizations
- Extract important insights from the analysis

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Kaggle

## 📊 Analysis Performed

### 1. Data Cleaning

Missing values were identified and handled before performing the
analysis.

### 2. Survival by Gender

The survival rates of male and female passengers were compared to
identify differences in survival outcomes.

### 3. Survival by Passenger Class

The survival rates of first, second, and third-class passengers were
analyzed.

### 4. Survival by Age Group

Passengers were divided into different age groups and their survival
rates were compared.

## 📈 Visualizations

The project includes:

- Survival rate by gender
- Survival rate by passenger class
- Survival rate by age group
- Passenger age distribution
- Survival count
- Survival by gender
- Survival by passenger class
- Correlation matrix

## 💡 Key Insights

The analysis identifies important relationships between passenger
characteristics and survival outcomes.

Gender and passenger class show noticeable differences in survival
rates, while survival also varies across different age groups.

## 📝 Conclusion

This project demonstrates the use of Python for data cleaning,
exploratory data analysis, visualization, and extracting meaningful
insights from a real-world dataset.
